# 利用者ガイド（プレイヤー向け）

このサーバーは、ログインして「いまのネットワークの IP アドレス」を登録した人だけが接続できます。遊ぶ前に、毎回ログインが必要です。

## 遊ぶまでの流れ

1. 管理者から共有されたログインページを開き、ユーザー名とパスワードでログインします。ログインページの URL は管理者から直接受け取ってください（この文書には載せていません）。初回は管理者から受け取った一時パスワードを、新しいパスワード（8 文字以上で、英大文字・英小文字・数字・記号をそれぞれ 1 文字以上含むもの。他のサービスと使い回さず、推測されにくいもの）に変更します。
2. 「登録しました」というページが出たら成功です。ページには**登録された IP アドレス**が表示されます。
3. 通常 1 分程度、サーバーが停止中だったときはそれに加えて起動の時間（数分）を待ちます。
4. ゲームからサーバーに接続します。起動中は接続に失敗することがありますが、少し待ってからもう一度試してください。

## 接続先

- **Java 版:** 管理者から共有されたサーバーのアドレス（ポート 25565）。
- **Bedrock 版:** 管理者から共有されたサーバーのアドレスと、ポート **19132**（UDP）。
- **自宅の LAN から接続する場合:** 接続先に、管理者から案内された **LAN 内のアドレス** を指定してください（Java 版はそのまま、Bedrock 版はポート 19132）。グローバル IP やドメイン名を指定すると、ルーターで折り返されて接続できません。

LAN や WireGuard から接続する場合、ログインは不要です。ただしサーバーが停止しているときは自動では起動しません。停止中なら、誰かがログインページで認証して起動してください（LAN の中から認証しても、LAN 内の人の接続には影響しません）。

## 守ってほしいこと（IP アドレスで制御しているための制約）

1. **遊ぶ端末と同じネットワークでログインしてください。** 登録されるのはログインした端末の IP アドレスです。たとえば、スマホのモバイル回線でログインして、自宅 Wi-Fi の PC で遊んでも接続できません。
2. **ログインするときは、iCloud プライベートリレー、ブラウザの IP 保護、VPN、プロキシをオフにしてください。** オンのままだと、中継サーバーの IP が登録されてしまいます。完了ページに表示された IP が、いま使っているネットワークの IP と合っているか確認してください。
3. **IPv4 で接続してください。** IPv4 以外では登録できません。
4. **途中で IP が変わると接続が切れます。** モバイル回線での移動や、プロバイダーによる IP の変更で起こります。その場合はもう一度ログインしてください。
5. **登録は、最後の通信から 10 分間有効です。** 通信している間は自動で延長されます。10 分間通信がなくなると失効し、接続が切れたら再ログインが必要です。これはゲームからのログアウトではありません。
6. **同じ IP を共有する人は、ポートまで到達できます。** 同居人、公衆 Wi-Fi、一部のモバイル回線などです。参加できる人はホワイトリスト（Minecraft のアカウント）で別に絞っています。ホワイトリストに登録されていないアカウントは、IP が登録されていても入れません。
7. **アカウントを無効にしても、すでに登録された IP が使えなくなるまでには時間がかかります。** 心当たりのないログインを見つけたら、すぐ管理者に連絡してください。
8. **全員がいなくなると、約 15 分後にサーバーが自動で止まります。** 次に遊ぶときは、もう一度ログインしてください。
9. **一部のモバイル回線では、同じ端末でログインしても接続できないことがあります。** 回線によっては、ログインの通信と Minecraft への通信で、外から見える IP アドレスが変わるためです。何度ログインしても解決しません。その場合は別の回線（自宅の固定回線など）で遊ぶか、管理者に相談してください。

## ログインページのメッセージ

| 表示 | 意味 | 対処 |
|---|---|---|
| 登録しました | IP を登録できた | 通常 1 分程度 + サーバー起動時間を待って接続する |
| 期限切れ・処理済みです | ログインの途中で時間が経った、またはタブを複数開いた | 最初のログインページからやり直す（タブは 1 つだけ使う） |
| 権限がありません | このアカウントでは接続できない | 管理者に連絡する |
| IPv4 以外からのアクセスです | IPv6 で接続している | IPv4 で接続して再度ログインする |
| アカウント設定に問題があります | アカウント側の設定の問題 | 管理者に連絡する |
| 一時的なエラー | 一時的な障害 | しばらくしてからやり直す |

## 接続できないとき

1. ログイン後、1 分以上たってから接続しているか（サーバーが停止中だった場合は数分かかります）。
2. 完了ページに表示された IP が、遊ぶ端末のネットワークの IP と合っているか。違う場合は VPN・プライベートリレーなどをオフにして、もう一度ログインする。
3. ログインした端末と遊ぶ端末が同じネットワークか。
   - 同じ端末・同じネットワークでも、モバイル回線（テザリングを含む）では接続できないことがあります（上の 9）。別の回線で試してください。
4. 最後の通信から 10 分以上たっていないか。たっていたらもう一度ログインする。
5. LAN から接続する場合に、管理者から案内された LAN 内のアドレスを指定しているか。
6. Minecraft のホワイトリストに登録されているか（管理者に確認）。

それでも接続できないときは、管理者に連絡してください。その際、ログインした時刻と、完了ページに表示された IP を伝えてください。
